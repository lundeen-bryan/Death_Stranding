# The Terrain Scanner: Icon Overview

| Icon | Meaning |
| --- | --- |
| Blue filled square | Safe terrain. |
| Yellow filled square | Steep terrain. Will deplete the Endurance Gauge. |
| Yellow warning triangle | Dangerous/treacherous terrain—easy to fall, etc. |
| Red X | Terrain too steep to be traversed. |
| Blue outlined square | Shallow water. |
| Yellow outlined square | Deep water. If the Endurance Gauge hits zero, you will be swept away. |
| Red outlined square | Very deep water. You will be swept away immediately. |
