# Porter Grade

## Overview

Porter Grade is divided into five independent categories. Completing different kinds of deliveries increases different categories, which permanently improve Sam's abilities.

| Category | Increased By | Permanent Benefit |
|----------|--------------|-------------------|
| 📦 Delivery Volume | Delivering large quantities of cargo | Increases maximum carrying capacity and cargo stability |
| ⚡ Delivery Time | Completing Premium Time-Focused Orders | Increases maximum stamina |
| 📦 Cargo Condition | Delivering cargo with little or no damage | Improves balance and reduces stumbling |
| 🌉 Bridge Link | Online interactions, player Likes, Strand Contracts, shared structures | Unlocks additional Strand Contracts and improves online features |
| ⭐ Miscellaneous | Recovery missions, lost cargo, miscellaneous delivery types | Increases Likes received and other general porter abilities |

## Known Gameplay Milestones

Most permanent upgrades occur around these levels within each individual category.

| Category Level | Effect |
|---------------:|--------|
| 10 | First noticeable improvement |
| 20 | Improved stat bonus |
| 30 | Moderate improvement |
| 40 | Significant improvement |
| 50 | Large improvement |
| 60+ | Continued scaling with fewer new unlocks |

## Best Ways to Level Each Category

| Goal | Best Activity |
|------|---------------|
| Delivery Volume | Large cargo deliveries and bulk Standard Orders |
| Delivery Time | Premium Time-Focused Orders |
| Cargo Condition | Deliver undamaged cargo (Premium Orders help) |
| Bridge Link | Build roads, bridges, generators, safe houses, signs, and receive player Likes |
| Miscellaneous | Recover lost cargo, recovery missions, miscellaneous delivery requests |

---

## Lost Cargo Notes

- Lost cargo delivered to its intended NPC often awards a large number of Likes.
- Lost cargo contributes toward facility connection levels.
- Delivering lost cargo can sometimes increase connection levels faster than small Standard Orders.
- Some optional preppers require reading mail between deliveries before their connection can continue increasing.
- If a prepper appears "stuck," rest in a Private Room, read any new mail, then continue deliveries.

---

## Strategy Notes

Current strategy:

- Raise every facility to **at least 3 stars** before advancing the story.
- Prioritize destinations below 3 stars.
- Pick up NPC lost cargo whenever it matches your destination.
- Combine lost cargo with Standard Orders for the same destination.
- Build roads and useful structures to increase Bridge Link while making future deliveries easier.
