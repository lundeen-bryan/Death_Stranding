# The Weather Forecast: Changing the Forecast Time

## Where this applies

This tip describes the **Weather overlay on the map you see when you activate the Cuff Links**. The controls below change the forecast time shown in that overlay.

*Context added for clarity; not part of the in-game transcription.*

## In-game text

**D-pad up** and **D-pad down** can be used to alter the time for which the weather forecast is being displayed.
