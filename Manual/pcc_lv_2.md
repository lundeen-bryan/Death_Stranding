# PCC (Lv. 2)

A PCC capable of fabricating advanced structures. Building a structure will take up some of the chiral bandwidth available to you. Structures can be shared with other players once built.

**New structures cannot be built within the area around an existing facility marked with sensor poles.**

Hold **2** and press **direction keys (W/A/S/D):** Select Structure

**Right mouse button (Hold):** Adjust Structure Location

**Left mouse button:** Build
