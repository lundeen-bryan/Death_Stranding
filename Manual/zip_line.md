# Zip-line

Creates an anchor, two of which can be connected in order to create a zip-line, enabling rapid travel from one end to the other. Level 1 zip-line anchors can be placed up to 300 meters apart. Zip-lines can be very useful for quickly traveling over steep slopes or rocky terrain.

**Vehicles and multiple linked floating carriers cannot travel via zip-line.**
