# Securing Cargo Using Strands

Hold **D-pad right** + **Right stick:** Equip Strand

You can use strands to secure cargo to carriers, trucks, etc.

Equip a strand, then use **LT (Hold)** to prepare it, and **RT** to secure your cargo.
