# Photo Mode

Press **D-pad down** to launch Photo Mode.

Camera angles, coloring and poses can be adjusted as you see fit. Note that there are certain areas in which Photo Mode cannot be used. Because free camera movement has been prioritized, it is possible that the camera will collide with other objects. Your platform's screenshot function can be used to save any photos you'd like to keep for posterity.

Choose whether or not to temporarily save changes to Photo Mode settings when closing Photo Mode by selecting "Options" → "Game Settings" → "Temporarily Save Settings in Photo Mode".
