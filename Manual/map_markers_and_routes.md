# Map Markers and Routes

You can add your own markers to the map accessed via the cuff links, and draw lines to help you plot a route to a destination. Any markers you place can also be viewed by using **LB (Hold)** to enter Compass Mode.

(If you are using a keyboard, press **G** again to leave Compass Mode.)
