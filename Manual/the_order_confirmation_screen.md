# The Order Confirmation Screen

Use **LB** and **RB** to switch tabs and view various information about an order.

- Order Summary: Order completion conditions, associated risks, etc.
- Order Details: A list of objectives for the order, etc.
- Cargo for Delivery: Various information about the order's cargo (weight, number of pieces, etc.)
- Supplies: Supplies that will be provided, etc.

==The amount of cargo each order involves, as well as its size, can also be viewed at the bottom of the screen.==
